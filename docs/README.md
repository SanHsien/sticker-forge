# 文件索引

本資料夾放 `sticker-forge` 的長期維護文件。根目錄 README 面向使用者；這裡面向維護者與接手的 AI。

## 入口

- [`HANDOFF.md`](HANDOFF.md)：目前接手狀態、已知風險、下一步。
- [`../REVIEW.md`](../REVIEW.md)：最新專案 review（在根目錄，僅保留最新版）。
- [`ARCHITECTURE.md`](ARCHITECTURE.md)：local-first 目標架構與 legacy 邊界。
- [`DEVELOPMENT.md`](DEVELOPMENT.md)：本機 app、測試與 exe 打包方向。
- [`ROADMAP.md`](ROADMAP.md)：fork 後整理與改寫計畫。
- [`DECISIONS.md`](DECISIONS.md)：重要決策紀錄。
- [`planning/`](planning/)：較細的規劃草稿與待辦拆解。

## 文件維護原則

- 使用繁體中文。
- 重要設計決策寫進 `DECISIONS.md`，不要只留在聊天紀錄。
- 任務交接狀態寫進 `HANDOFF.md`。
- 大型重構前先更新 `ARCHITECTURE.md` 或在 `planning/` 放草案。
