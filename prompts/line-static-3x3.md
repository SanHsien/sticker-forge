# LINE 靜態貼圖 3x3 生成提示詞

用途：讓使用者複製到 ChatGPT、Gemini 或其他生圖工具，產生可匯回 `sticker-forge` 的 3x3 貼圖 grid。

## 填寫欄位

- 角色設定：`{character}`
- 主題：`{theme}`
- 語氣：`{tone}`
- 圖像風格：`{style}`
- 語言：`{language}`
- 貼圖文字 1-8：`{text_1}` 到 `{text_8}`
- 動作描述 1-8：`{action_1}` 到 `{action_8}`

## 有字版

請生成一張 3x3 grid 的 LINE 靜態貼圖素材圖。

規格：

- 角色：`{character}`
- 主題：`{theme}`
- 語氣：`{tone}`
- 風格：`{style}`
- 語言：`{language}`
- 版面：3 欄 x 3 列，共 9 格，每格是獨立貼圖構圖
- 背景：純色 `{chroma_key_label}` (`{chroma_key_hex}`)，方便後續 chroma-key 去背
- 輸出：單張正方形圖片，九宮格間距清楚
- 每格角色保持一致，不要變成不同人物
- 每格只放一個主要角色，不要複雜場景
- 每格文字要短、清楚、置中或靠近角色，不要被裁切
- 角色、衣服、道具、陰影與反光都不要使用 `{chroma_key_avoid}`；若角色原本接近背景色，改用 `{chroma_key_substitutions}`

九宮格內容：

1. `{text_1}`，動作：`{action_1}`
2. `{text_2}`，動作：`{action_2}`
3. `{text_3}`，動作：`{action_3}`
4. `{text_4}`，動作：`{action_4}`
5. `{text_5}`，動作：`{action_5}`
6. `{text_6}`，動作：`{action_6}`
7. `{text_7}`，動作：`{action_7}`
8. `{text_8}`，動作：`{action_8}`
9. 空白備用格，保持同一角色與風格，不加文字

避免內容：

- 不要使用既有 IP、商標、品牌角色、名人、政治人物或真人肖像
- 不要生成色情、仇恨、暴力、詐騙、個資或可能侵權的內容
- 不要宣稱 LINE 官方、認證或保證上架通過
